# แพ็กตัวอย่าง 02: FAQ โรงพยาบาลสมมติ (ขยายสำนวน)

ข้อมูลสมมติทั้งหมด (ยกเว้นสายด่วนจริง 1323 สุขภาพจิต, 1669 การแพทย์ฉุกเฉิน)
- `facts.json` — 16 เรื่อง: คำตอบ + คำถาม 9-16 แบบ + คำสำคัญ (คำถามข้อสุดท้ายของแต่ละเรื่อง = ข้อสอบ)
- ระบบขยายเป็นราว 370 ตัวอย่าง (แต่ละคำถามมี 2 สำนวน คำตอบ 3 สำนวนต่อเรื่องจาก `answers_alt` + ตัวอย่างทักทาย/ตัวตน + คำถามนอกขอบเขต 32 ข้อที่สอนให้ตอบ "ไม่มีข้อมูล" 4 สำนวน) และสร้างข้อสอบ 26 ข้อ (16 จากข้อเท็จจริง + 2 ทั่วไป + 8 นอกขอบเขต) เดิม (0.8.0 ลงไป) คูณคำนำหน้า 5 แบบได้ราว 840 ตัวอย่างแต่ซ้ำจนโมเดลท่องจำ
- แก้ `facts.json` หรือสร้างเองในหน้า "ชุดข้อมูลเทรน → สร้างจากตารางข้อเท็จจริง" ได้

## โหลด
```
cd backend
python load_sample_pack.py --reset --kb
```
(`--reset` ล้างโจทย์ทดสอบ/ชุดข้อมูลเองเดิม, `--kb` ใส่ข้อเท็จจริงเข้าคลังความรู้ด้วย)

## ตั้งค่าเทรนที่แนะนำ (RTX 3050 4GB)
โมเดล typhoon2-3b · epochs 2 (พรีเซ็ต "FAQ ชุดข้อมูลเล็ก" ตั้งให้แล้ว) · learning rate 0.0002 · r/alpha 32/32 · max_seq_length 512 · ขนาดตัวอย่าง ~370
(ราว 250 step) ก่อนเริ่ม `ollama stop` ทุกโมเดลและเช็ค `nvidia-smi`
