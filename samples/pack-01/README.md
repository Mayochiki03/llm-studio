# แพ็กตัวอย่าง 01: FAQ โรงพยาบาลสมมติ

ข้อมูล **สมมติทั้งหมด** (ชื่อหน่วยงาน เบอร์ เวลา) ไม่ใช่ข้อมูลผู้ป่วยหรือข้อมูลจริงของโรงพยาบาลใด
มีไว้ฝึกทั้งวงจร: เทรน → ทดสอบ → ดูว่าผ่านเกณฑ์ไหม (ยกเว้นเบอร์สายด่วนจริง 1323 สุขภาพจิต และ 1669 การแพทย์ฉุกเฉิน)

- `train.jsonl` — 70 คู่ถามตอบ (12 หัวข้อ × 4 แบบคำถาม + เคสปลอดภัย + คุยทั่วไป/ปฏิเสธเรื่องที่ไม่รู้)
- `eval-prompts.json` — 16 โจทย์ทดสอบ **คนละประโยคกับข้อเทรน** (ถามเรื่องเดียวกันด้วยคำอื่น) พร้อมคำที่ต้องมี (`expect`) / ห้ามมี (`must_not`) และเคส red flag
- `_generate.py` — สคริปต์สร้างสองไฟล์ข้างบน (แก้ข้อมูลที่นี่แล้วรันใหม่ได้)

## วิธีโหลดเข้าระบบ

```
cd backend
python load_sample_pack.py --reset     # ล้างโจทย์/ชุดข้อมูลเองเดิม แล้วโหลดแพ็ก (ไม่ต้องปิด backend)
```
ไม่ใส่ `--reset` = เพิ่มแพ็กเข้าไปโดยไม่ล้างของเดิม

## ตั้งค่าเทรนที่แนะนำ (RTX 3050 4GB)
โมเดล `typhoon2-3b` · พรีเซ็ต quality · epochs 4-5 · max_seq_length 512 · ขนาดตัวอย่าง = ทั้งชุด (70) ·
ก่อนเริ่ม `ollama stop` โมเดลที่ค้าง + เช็ค `nvidia-smi`
